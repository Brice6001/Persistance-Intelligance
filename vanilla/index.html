Standalone Obtaining & Setting Up Your Gemini API Key

Step-by-Step API Key Obtainment

  1. Navigate to Google AI Studio: aistudio.google.com
  2. Authenticate using your standard Google user account credentials.
  3. Click on the prominent Get API Key button on the sidebar.
  4. Choose to create a key either in a new cloud project or synchronize with an existing administrative workspace.
  5. Copy the generated alphanumeric string (starting with AIzaSy...).

Offline Local Execution instructions

To run this vanilla copy directly on your personal machine or hosted file share:

  • Save these files locally as index.html, style.css, and script.js in a single directory.
  • Open index.html in any web browser.
  • Paste your Gemini API key in the top right configuration text box.
  • Run prompts to generate on-the-fly schemas dynamically!
